# vue-sneakers-shop

https://youtu.be/U_-Ht_v-oAs?si=YgYvzRvzNcUptXLA

Добавлено дополнительно сверх программы:

1. Состояние "добавлено в избранное" при применении фильтра по названию (текстовый инпут) и при сортировке
2. Состояние "добавлено в корзину" при применении фильтра по названию (текстовый инпут) и при сортировке
3. Фикс удаления из корзины (поиск товара для удаления производится не по объекту, а по ключу id, иначе при расхождении информации в корзине и реального объекта товара, например, в состоянии favorite, удалялся первый элемент в корзине, а не искомый)
